Query pages and print matching file paths as a Markdown bullet list

Usage: traces list [OPTIONS]

Options:
      --from <FROM>     Source expression, e.g. `#tag`, `folder/`, `@Class*`, or a boolean combination. Omit to query every indexed page
      --where <FILTER>  Filter expression narrowing results, e.g. `"file.folder == \"books\""`. Repeatable; multiple `--where` flags compose as AND
      --sort <KEYS>...  Field path to sort by. Repeatable; multiple `--sort` flags or comma-separated values compose as composite sort terms. Defaults to descending order unless overridden by prefix `+` or the `--asc` flag
      --asc             Sort in ascending order. Conflicts with `--desc`. Requires `--sort`
      --desc            Sort in descending order (the default). Conflicts with `--asc`. Requires `--sort`
  -h, --help            Print help
